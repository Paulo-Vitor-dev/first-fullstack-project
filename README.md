# ▶️ Como Executar o Projeto

## 📦 Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

---

# 🔧 Backend

Entre na pasta:

```bash
cd backend
```

Instale as dependências:

```bash
npm install
```

Crie o arquivo `.env`:

```env
DATABASE_URL=
PORT=5000
```

Execute o servidor:

```bash
node --watch server.js
```

---

# 💻 Frontend

Entre na pasta:

```bash
cd frontend
```

Instale as dependências:

```bash
npm install
```

Execute a aplicação:

```bash
npm run dev
```
